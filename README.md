A simple, Material You themed calculator with a built-in parser designed to mimic the Google calculator app but for the web. You can also install Calculite as a web application on your desktop or your phone.

## Features

### Website and Chrome Extension

- Infinitely customizable themed
- Always stay awake mode
- Calculation history with notes
- Offline PWA access
- Integrates beautifully with your system
- Secure with custom AST parser

### Chrome Extension

- Calculate anything in your address bar
- Calculate selections in the context menu
- Calculate and replace selections in the context menu
- Open Calculite in the sidebar
